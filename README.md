# BYD Battery — чтение данных батареи через ELM327

Android-приложение подключается к адаптеру ELM327 (Bluetooth Classic / SPP) и раз в секунду
опрашивает BMS: заряд, точный заряд, ёмкость, напряжение, ток, температуру ВВБ, мощность.

## Как получить APK без Android Studio
1. Создайте пустой репозиторий на github.com (можно приватный).
2. Загрузите туда все файлы этого архива, сохранив структуру папок
   (Add file → Upload files, перетащите содержимое папки, включая скрытую `.github`).
3. Откройте вкладку **Actions** — сборка запустится сама (около 3–5 минут).
4. Откройте завершённый запуск и скачайте артефакт **BydBattery-apk** (zip с APK внутри).
5. Установите APK на телефон (разрешите установку из неизвестных источников).

## Как пользоваться
1. Вставьте адаптер в OBD-разъём, включите зажигание.
2. В настройках Bluetooth телефона сопрягите адаптер (PIN обычно 1234 или 0000).
3. В приложении: «Подключить» → выберите адаптер. Опрос начнётся автоматически.
4. Под каждым значением видны сырые байты ответа или текст ошибки.
5. Терминал позволяет отправить любую команду (например `ATSH7E7`, `220005`).
6. «Поделиться» — отправить лог (удобно для подбора PID).

## Важно про BYD e2
Идентификаторы (22 0005, 1FFC, 1FFE, 0008, 0009, 0032 по адресу 7E7) взяты из открытых профилей
WiCAN для BYD Atto 3 / Dolphin / Seal. Для e2 они не проверены. Если значения не приходят
или выглядят странно — включите «Подробный лог» и пришлите лог: по сырым ответам можно подобрать
правильные адреса и формулы (файл `Params.kt`).
