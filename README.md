# BYD Battery — диагностика батареи BYD e2 через ELM327

Android-приложение для чтения данных высоковольтной батареи **BYD e2 (43,2 кВт·ч)** через Bluetooth-адаптер
ELM327 v1.5 (Bluetooth Classic / SPP).

Текущая версия: **3.0**

## Возможности

- Заряд (как на приборке и точный от BMS), напряжение, ток, температура батареи.
- Минимальная и максимальная ячейка с номерами, разброс напряжений **ΔV**.
- Минимальная и максимальная температура с номерами датчиков, разброс **ΔT**.
- Фактическая и номинальная ёмкость, оценка SOH.
- Счётчики полученных и отданных ампер-часов за всё время, эквивалент полных циклов.
- Мощность, режим (заряд / разряд / покой), C-rate, запас и остаток энергии, счётчики энергии.
- Сводка по 7 модулям батареи: ΔV и температура каждого модуля.
- Неизвестный параметр каждой из 90 ячеек (для наблюдения за изменениями со временем).
- Сканер BMS: перебор идентификаторов с сохранением ответов в файл.
- Терминал для ручных команд ELM327 / UDS и журнал обмена.

Приложение только **читает** данные (сервис UDS 0x22) и ничего не записывает в блоки автомобиля.

## Сборка APK без Android Studio

1. Загрузите содержимое проекта в репозиторий GitHub (вместе со скрытой папкой `.github`).
2. Откройте вкладку **Actions** — сборка запустится автоматически (3–5 минут).
3. Откройте завершённый запуск, внизу в разделе **Artifacts** скачайте **BydBattery-apk**.
4. Распакуйте архив и установите `app-debug.apk` на телефон (разрешите установку из неизвестных источников).

Новая версия устанавливается поверх старой.

## Использование

1. Вставьте адаптер в OBD-разъём, переведите машину в режим **READY**.
2. Сопрягите адаптер в настройках Bluetooth телефона (PIN обычно `1234` или `0000`).
3. В приложении нажмите **«Подключить»** и выберите адаптер. Опрос начнётся автоматически (раз в секунду).
4. Под каждым параметром показаны сырые байты ответа или текст ошибки.
5. **«Прочитать модули и ячейки»** — таблица по модулям и значения по ячейкам (10–20 секунд).
6. **«Запустить скан»** — быстрый (~1 мин) или полный (~7 мин) перебор идентификаторов.
   Файл сохраняется в памяти приложения, отправить его можно кнопкой **«Отправить файл»**.

Держите приложение открытым на экране во время скана: при сворачивании Android может его остановить.

## Параметры BMS BYD e2

Адрес BMS: **7E7** (ответ 7EF), CAN 11 бит 500 кбит/с (`ATSP6`).
Инициализация: `ATZ ATE0 ATL0 ATH0 ATSP6 ATAT1 ATST96 ATSH7E7 ATFCSH7E7 ATFCSD300000 ATFCSM1`.

Запрос: `22 XXXX`, ответ: `62 XX XX d0 d1 …`. В формулах `d0` — первый байт данных,
`LE16 = d0 + d1×256`, `LE24 = d0 + d1×256 + d2×65536`.

### Подтверждённые

| DID | Параметр | Формула | Пример |
|---|---|---|---|
| 0005 | Заряд (как на приборке), % | d0 | 94 |
| 1FFC | Заряд BMS точный, % | LE16(d0,d1) / 100 | 93,90 |
| 0008 | Напряжение батареи, В (шаг 1 В) | LE16 | 300 |
| 0009 | Ток, А (минус — заряд, плюс — разряд) | LE16 × 0,1 − 500 | 0,6 / −4,1 |
| 0032 | Температура батареи, °C | d0 − 40 | 16 |
| 002A | Номер минимальной ячейки (1–90) | d0 | 78 |
| 002B | Напряжение минимальной ячейки, мВ | LE16 | 3326 |
| 002C | Номер максимальной ячейки | d0 | 1 |
| 002D | Напряжение максимальной ячейки, мВ | LE16 | 3330 |
| 002E | Номер датчика минимальной температуры | d0 | 7 |
| 002F | Минимальная температура, °C | d0 − 40 | 16 |
| 0030 | Номер датчика максимальной температуры | d0 | 2 |
| 0031 | Максимальная температура, °C | d0 − 40 | 17 |

### Сводка по модулям (016C–01A3)

7 групп по 8 идентификаторов, группа модуля N начинается с `016C + (N−1)×8`:

| Смещение | Параметр | Формула |
|---|---|---|
| +0 | Номер минимальной ячейки в модуле (с 0) | d0 |
| +1 | Напряжение минимальной ячейки, мВ | LE16 |
| +2 | Номер максимальной ячейки в модуле (с 0) | d0 |
| +3 | Напряжение максимальной ячейки, мВ | LE16 |
| +4 | Номер датчика минимальной температуры | d0 |
| +5 | Минимальная температура, °C | d0 − 40 |
| +6 | Номер датчика максимальной температуры | d0 |
| +7 | Максимальная температура, °C | d0 − 40 |

Номер датчика температуры в 002E/0030 совпадает с номером модуля.
Модули, по-видимому, разного размера, поэтому соответствие номеров ячеек внутри модуля
и сквозных номеров (002A/002C) пока не установлено.

### Вероятные (согласуются с данными, но не подтверждены полностью)

| DID | Параметр | Формула | Пример | Обоснование |
|---|---|---|---|---|
| 1FFC | Фактическая ёмкость, А·ч | LE16(d2,d3) / 100 | 146,28 | рядом с SOC, ~97 % от номинала |
| 1FFE | Номинальная ёмкость, А·ч | LE16(d2,d3) / 100 | 150,80 | 90 × 3,2 В × 150 А·ч = 43,2 кВт·ч |
| 000F | Отдано за всё время, А·ч | LE24 | 21 670 | ≈ 19 кВт·ч/100 км на пробеге 34 584 км |
| 0010 | Получено за всё время, А·ч | LE24 | 22 055 | больше отданного на величину потерь |
| 0006, 0007 | Ёмкость, 0,1 А·ч | LE16 / 10 | 146,2 | почти совпадает с 1FFC |

### Неизвестные

| DID | Значение | Наблюдения |
|---|---|---|
| 0029 | 98 | не меняется; возможно SOH, % |
| 0040–0099 | 273–345 (LE16) | ровно 90 значений — по одному на ячейку; не меняются при заряде; не напряжения и не температуры (возможно внутреннее сопротивление или ёмкость ячейки) |
| 000A / 000B | 472 / 361 | почти не меняются при слабом заряде; возможно лимиты, требуется скан на DC-зарядке |
| 0015 | 7623 → 7296 | уменьшился при подключении зарядки; возможно сопротивление изоляции |
| 0017, 0018 | 2,1 → 1,0 | изменились при подключении зарядки; возможно флаги состояния заряда |
| 1FFE d0–d1 | 6470 | не меняется |
| 0004, 000E, 0011–0014, 0016–0028, 0033–0037, 0A04–0A20, 1FEF–1FFB | — | не исследованы |
| F193, F194, F195, F1F3 | — | вероятно версии ПО и оборудования BMS |

Напряжения отдельных ячеек в диапазонах 0000–0FFF, 1F00–1FFF и F180–F1FF не найдены.

## Конфигурация батареи

- Химия: LFP, ёмкость 43,2 кВт·ч.
- 90 ячеек последовательно, номинал около 150 А·ч, 3,2 В на ячейку.
- 7 модулей, 7 датчиков температуры (по одному на модуль).

## Дальнейшие исследования

- Скан при низком заряде (20–30 %) на быстрой DC-зарядке — поиск лимитов заряда.
- Скан во время поездки — лимиты разряда и рекуперации.
- Наблюдение за 0029 и 0040–0099 на протяжении месяцев.

## Ограничения

- Поддерживаются только адаптеры Bluetooth Classic (SPP); адаптеры Bluetooth LE не поддерживаются.
- Параметры проверены на одном автомобиле BYD e2; на других моделях и версиях BYD адреса могут отличаться.
- Приложение не является официальным диагностическим инструментом BYD.
